# 🧑‍💼 Customer Churn Prediction

## 📌 Project Overview

This project is an end-to-end Machine Learning project focused on predicting customer churn.

The objective is to identify customers who are likely to leave a service and determine the main factors associated with customer churn. The project follows a complete Data Science workflow, from data exploration and preprocessing to model training, evaluation, and business interpretation.

## 🎯 Objectives

* Analyze customer behavior and identify churn patterns.
* Explore the main factors influencing customer churn.
* Prepare and transform the dataset for Machine Learning.
* Build and compare several classification models.
* Evaluate model performance using appropriate classification metrics.
* Identify the most important features associated with customer churn.
* Provide actionable business insights.
